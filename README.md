## 📚 Study Plan

This repository follows a **12-week AI Engineer Bootcamp** covering:

- 🐍 Python & Programming
- 📊 Math, Statistics & EDA
- 🤖 Machine Learning
- 🧠 Deep Learning with PyTorch
- 🗣️ Natural Language Processing
- 🔍 Transformers & LLMs (HuggingFace, T5, BERT)
- 🦜 LangChain, RAG, Groq, Ollama
- 🧑‍💼 Agentic AI (CrewAI, LangGraph)
- ☁️ GenAI Deployment, LLMOps & Capstone Projects

Each week contains:
- ✅ Daily topics with exercises
- 🧪 Real-world projects
- 🧾 Notebook-based implementation
- 🗂️ Tracked commits & progress

📁 All notes, code, notebooks, and project demos will be uploaded weekly.
