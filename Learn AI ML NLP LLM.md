# 🛠️ 5 Practical Real-Time AI Projects (Vision + Voice + Data Extraction)

---

### 1. **Smart Invoice Parser (Key-Value Extractor)**

**Goal**: Extract structured data (invoice number, date, vendor, items, totals, GST) from PDFs, images, and emails.

- **Input**: Invoice (PDF/PNG)
- **Output**: JSON with fields: `invoice_no`, `date`, `vendor`, `line_items`, `gst`, `total`
- **Features**:
    - OCR with Tesseract or LayoutLMv3
    - Key-Value detection using trained NLP model (or rule-based fallback)
    - Table extraction with image-based region detection
- **Bonus**: Integrate with Tally, Zoho Books, QuickBooks
- **Stack**: PyMuPDF / pdfplumber + PaddleOCR + HuggingFace + LangChain for metadata parsing

---

### 2. **Voice-Powered Assistant (Local or Web Agent)**

**Goal**: Build a voice-controlled assistant that takes spoken input, interprets intent, and performs tasks or gives responses.

- **Input**: Microphone (speech)
- **Output**: Speech response and/or action
- **Features**:
    - Speech-to-Text (Whisper)
    - Intent detection (OpenAI, LLM prompt)
    - Text-to-Speech (TTS via Coqui / pyttsx3 / ElevenLabs)
    - Actions: read emails, tell time, retrieve summary
- **Stack**: Whisper + LangChain + TTS + Streamlit Web UI (optional)
- **Bonus**: Deploy as desktop app or Alexa-style voice CLI

---

### 3. **Real-Time Product Image Finder (Vision + Search)**

**Goal**: Let users capture/upload an image of a product and get similar items with metadata (title, price, rating).

- **Input**: Product image from webcam/upload
- **Output**: List of similar products (title, price, image, link)
- **Features**:
    - Image embeddings (CLIP or BLIP2)
    - FAISS/ChromaDB vector search
    - Match with stored product catalog (text + images)
- **Use Case**: Retail/eCommerce AI
- **Stack**: PyTorch + CLIP + LangChain + Chroma + HuggingFace

---

### 4. **Business Card Reader → Contact Book Filler**

**Goal**: Take a photo of a business card and extract contact details (name, phone, email, org).

- **Input**: Photo of business card
- **Output**: Structured contact record (JSON or CSV)
- **Features**:
    - OCR + regex for email/phone
    - NER for name/organization extraction
    - Add contact to Airtable or Google Contacts
- **Bonus**: Build mobile app with Expo + FastAPI backend
- **Stack**: EasyOCR + SpaCy + regex + LangChain

---

### 5. **Retail Shelf Monitor (Real-Time Detection & Labeling)**

**Goal**: Use a webcam to detect product arrangement, price labels, and missing items in retail shelves.

- **Input**: Live video feed or shelf image
- **Output**: Bounding boxes, labels, alerts
- **Features**:
    - Object detection (YOLOv8 / Detectron2)
    - Real-time video inference with OpenCV
    - Label overlap detection, shelf planogram validation
- **Bonus**: Alert system or Telegram bot for managers
- **Stack**: PyTorch + YOLOv8 + OpenCV + Flask or FastAPI
